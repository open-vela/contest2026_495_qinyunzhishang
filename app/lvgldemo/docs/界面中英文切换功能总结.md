## 1. 功能概述

### 1.1 功能定义

本功能为 BES2800BP 开发板的 LVGL 界面提供**中英文双语切换**能力，覆盖设备上所有界面页面的文字与字体显示。

| 功能 | 说明 |
|------|------|
| **语言选择** | 用户在「设置 → 语言」页面选择「简体中文」或「English」 |
| **持久化保存** | 语言配置保存到 `/emmc/lang_config` 文件，重启后保持上次选择 |
| **即时切换** | 确认后无需重启，界面立即刷新为新语言 |
| **全页面覆盖** | 主页、菜单、设置、AI、会议、相机、录音、播放器等所有页面均适配 |
| **字体适配** | 中英文分别加载不同字号的 FreeType 字体，避免中文过大或英文过小 |
| **状态拦截** | 通话/录音/会议进行中禁止切换语言，避免资源冲突 |

### 1.3 设计约束

| 约束 | 说明 |
|------|------|
| **内存受限** | NuttX RTOS 嵌入式环境，堆内存有限，不能频繁 malloc/free |
| **FreeType 字体昂贵** | 单个 FreeType 字体加载占用数十 KB，需复用而非重建 |
| **LVGL 异步渲染** | 删除字体时若有 label 仍在引用，会触发 Usage Fault 死机 |
| **页面生命周期复杂** | 常驻页（主页）与非驻留页（功能页）刷新策略不同 |

## 2. 整体架构设计

### 2.1 方案选型：方案 B + 局部方案 C

本功能采用**混合方案**，兼顾内存效率与刷新实时性：

```
┌─────────────────────────────────────────────────────────────────┐
│  方案 B：集中式字符串表（全局语言变量 + i18n_get 查表）          │
│  ─────────────────────────────────────────────────              │
│  • 所有界面文字集中定义在 i18n.c 的 s_strings 二维数组          │
│  • 全局变量 g_current_lang 记录当前语言                          │
│  • 页面通过 i18n_get(STR_xxx) 获取当前语言对应字符串             │
│  • 优点：零冗余、易维护、新增字符串只需加一行                    │
│  • 缺点：非驻留页切换语言后不会自动刷新，需重建页面              │
├─────────────────────────────────────────────────────────────────┤
│  局部方案 C：语言变更回调（仅常驻页用）                          │
│  ─────────────────────────────────────────────────              │
│  • main_screen（主页）注册 lang_changed_cb 回调                  │
│  • 切语言后回调被触发，主页原地刷新字体/文字（无需重建屏幕）     │
│  • 优点：避免主页重建带来的闪烁，节省内存                        │
│  • 适用场景：主页的时钟/日期需要按语言切换字号和格式             │
└─────────────────────────────────────────────────────────────────┘
```

## 3. 核心模块：i18n 国际化模块

### 3.1 模块职责

[i18n.c](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/i18n.c) / [i18n.h](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/i18n.h) 是整个语言切换功能的核心，提供以下能力：

| 能力 | 函数 | 说明 |
|------|------|------|
| 初始化 | `i18n_init()` | 开机调用，从文件读取语言配置 |
| 获取字符串 | `i18n_get(STR_xxx)` | 查表返回当前语言对应文字 |
| 获取/设置语言 | `i18n_get_lang()` / `i18n_set_lang()` | 读取/切换当前语言 |
| 字体应用 | `i18n_apply_font()` / `i18n_apply_font_small()` | 给 label 应用 28px/24px 字体 |
| 字体获取 | `i18n_get_cjk_font()` / `i18n_get_cjk_font_small()` | 获取共享字体指针 |
| 回调注册 | `i18n_register_lang_cb()` | 常驻页注册语言变更回调 |
| 延迟广播 | `i18n_flush_lang_changed()` | 退出语言页时广播给常驻页 |
| 页面重建 | `i18n_rebuild_current_page()` | 销毁所有功能页，重建设置页 |

### 3.2 全局状态变量

```c
/* 当前语言（开机时从文件读取，默认中文） */
static lang_t g_current_lang = LANG_ZH_CN;

/* 共享的中文 FreeType 字体（28px，懒加载，用于标题） */
static lv_font_t *s_cjk_font = NULL;

/* 共享的中文 FreeType 字体（24px，懒加载，用于正文/UI提示） */
static lv_font_t *s_cjk_font_small = NULL;

/* 语言变更回调列表（主页等常驻页注册） */
static lang_changed_cb s_lang_cbs[MAX_LANG_CBS];  // 最多4个回调
static bool s_lang_pending = false;  // 延迟广播标记
```

### 3.3 初始化流程

开机时在 [lvgldemo.c:601](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/lvgldemo.c#L601) 调用 `i18n_init()`，**必须在创建任何 UI 之前调用**：

```
i18n_init()                           [i18n.c]
  │
  ├─ i18n_load_lang_from_file()
  │    ├─ open("/emmc/lang_config", O_RDONLY)
  │    ├─ 文件不存在 → 返回 LANG_ZH_CN（首次开机默认中文）
  │    ├─ read(fd, buf, 8)
  │    └─ strncmp(buf, "en", 2) == 0 → LANG_EN，否则 LANG_ZH_CN
  │
  ├─ g_current_lang = 读取结果
  ├─ syslog("[i18n] init, lang=en/zh")
  └─ 不预加载字体（懒加载，首次使用时才加载）
```

**关键设计：懒加载字体**

字体不在 `i18n_init()` 时加载，而是首次调用 `i18n_apply_font()` 或 `i18n_get_cjk_font()` 时才加载。原因：
1. 节省启动时间（FreeType 字体加载耗时约 100ms）
2. 节省内存（若用户从不切换语言，英文模式无需加载 CJK 字体）
3. 但实际上中英文模式都会加载（英文模式下语言页仍需显示"简体中文"）

## 4. 字符串表设计

### 4.1 字符串 ID 枚举

所有界面文字都定义在 [i18n.h](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/i18n.h) 的 `str_id_t` 枚举中，按页面分组：

```c
typedef enum {
    /* 主界面 */
    STR_HOME_DATE_FMT,          /* "%d月%d日" / "%b %d" */
    STR_HOME_WEEK_SUN,          /* 星期日 / Sun */
    ...

    /* 菜单页 */
    STR_MENU_AI,                /* 语音对话 / AI Assistant */
    STR_MENU_MEETING,           /* 会议模式 / Meeting */
    STR_MENU_CAMERA,            /* 图文智录 / AI Camera */
    ...

    /* 语言选择弹窗 */
    STR_LANG_DIALOG_TITLE,      /* 选择语言 / Select Language */
    STR_LANG_SWITCH_OK,         /* 切换成功 / Switch success */
    ...

    STR_COUNT  // 总数，用于数组边界检查
} str_id_t;
```

### 4.2 二维字符串表

字符串存储在 [i18n.c](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/i18n.c) 的 `s_strings[LANG_COUNT][STR_COUNT]` 二维数组中，**编译期确定，存放在 rodata 段**：

```c
static const char *const s_strings[LANG_COUNT][STR_COUNT] = {
    [LANG_ZH_CN] = {
        [STR_MENU_AI]      = "语音对话",
        [STR_MENU_MEETING] = "会议模式",
        [STR_MENU_CAMERA]  = "图文智录",
        ...
    },
    [LANG_EN] = {
        [STR_MENU_AI]      = "AI Assistant",
        [STR_MENU_MEETING] = "Meeting",
        [STR_MENU_CAMERA]  = "AI Camera",
        ...
    }
};
```

**设计要点**：
- 使用 C99 指定初始化器 `[STR_xxx] = "..."`，未赋值的项自动为 NULL
- `const` 修饰符确保字符串不可变，编译器可优化
- 二维数组结构使得 `i18n_get()` 只需一次数组索引：`s_strings[g_current_lang][id]`

### 4.3 字符串获取函数

```c
const char *i18n_get(str_id_t id)
{
    if (id < 0 || id >= STR_COUNT) {
        return "";
    }
    return s_strings[g_current_lang][id];
}
```

**使用示例**（在各页面中）：
```c
lv_label_set_text(title, i18n_get(STR_CAM_TITLE));      // 相机页标题
lv_label_set_text(btn, i18n_get(STR_MENU_SETTINGS));    // 菜单项
lv_label_set_text(status, i18n_get(STR_AI_LISTENING));  // AI状态
```

### 4.4 特殊处理：日期格式

主页日期格式中英文差异较大，使用格式化字符串 + 运行时拼接：

| 语言 | 格式串 | 示例 |
|------|--------|------|
| 中文 | `"%d月%d日"` | `7月21日` |
| 英文 | `"%s %d"` | `Jul 21` |

英文模式需额外用月份索引查 `i18n_en_months[12]` 表获取月份缩写：
```c
const char *const i18n_en_months[12] = {
    "Jan", "Feb", "Mar", "Apr", "May", "Jun",
    "Jul", "Aug", "Sep", "Oct", "Nov", "Dec"
};
```

实现见 [xiaoq_page.c:190-199](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/xiaoq_page.c#L190-L199) 的 `homepage_update_datetime()`。

## 5. 字体管理体系

### 5.1 字体资源

所有界面共用一个字体文件：`/emmc/font/MiSans-Normal.ttf`

MiSans 字体特点：
- **包含中英文**：同时覆盖 CJK 统一汉字和拉丁字母
- **中英文模式均可用**：英文模式下也加载此字体（避免切换时频繁创建/删除）
- **FreeType 渲染**：使用 LVGL 的 FreeType 插件按需渲染指定位图

### 5.2 共享字体层级

```
┌──────────────────────────────────────────────────────────────┐
│  共享字体（i18n.c 管理，全局单例，懒加载）                    │
│                                                              │
│  s_cjk_font (28px)        ── 用于标题、按钮文字              │
│  s_cjk_font_small (24px)  ── 用于正文、状态提示、列表项      │
│                                                              │
│  加载时机：首次调用 i18n_apply_font / i18n_get_cjk_font 时   │
│  释放时机：永不释放（避免堆碎片，复用）                       │
├──────────────────────────────────────────────────────────────┤
│  主页私有字体（xiaoq_page.c 管理）                            │
│                                                              │
│  time_font     ── 时钟数字（中文120px，英文100px）           │

│                                                              │
│  cam_title_font (28px)   ── 相机页标题                       │
│  cam_btn_font (24px)     ── 相机页按钮                       │
│  meeting_title_font (28px) ── 会议页标题                     │
│  ...                                                         │
│                                                              │
```

### 5.3 字体应用函数

#### i18n_apply_font（28px 标题字号）

```c
void i18n_apply_font(lv_obj_t *obj)
{
    i18n_ensure_cjk_font();  // 懒加载
    if (s_cjk_font) {
        lv_obj_set_style_text_font(obj, s_cjk_font, 0);
        return;
    }
    /* CJK 字体加载失败：fallback 到 montserrat_24 */
    lv_obj_set_style_text_font(obj, &lv_font_montserrat_24, 0);
}
```

**中英文模式均使用 MiSans 28px**，原因：
1. MiSans 含拉丁字符，英文模式下同样可读
2. 保证字号一致，避免切换语言时布局跳动
3. 历史 Bug：原英文模式回退到 montserrat_24（24px）偏小，已修复

#### i18n_apply_font_small（24px 正文字号）

```c
void i18n_apply_font_small(lv_obj_t *obj)
{
    if (g_current_lang == LANG_ZH_CN) {
        i18n_ensure_cjk_font();
        if (s_cjk_font_small) {
            lv_obj_set_style_text_font(obj, s_cjk_font_small, 0);
            return;
        }
        /* 24px 加载失败则 fallback 到 28px */
        if (s_cjk_font) {
            lv_obj_set_style_text_font(obj, s_cjk_font, 0);
            return;
        }
    }
    /* 英文模式或中文字体都失败：用 montserrat_24 */
    lv_obj_set_style_text_font(obj, &lv_font_montserrat_24, 0);
}
```

**用途**：录音/播放器/WiFi 等界面的非标题文字（文件列表、计时、状态提示），避免中文 28px 过大导致挤压。

### 5.4 字体获取函数

```c
lv_font_t *i18n_get_cjk_font(void)         // 28px
lv_font_t *i18n_get_cjk_font_small(void)   // 24px
```

**关键修复**：这两个函数**总是确保字体已加载并返回**，无论中英文模式。

历史 Bug：
- 之前英文模式返回 NULL → 选项文字 fallback 到 montserrat（不含中文）→ 显示方框
- 切换语言后渲染访问空字体指针 → `lv_font_get_glyph_width` 崩溃
- 修复：始终调用 `i18n_ensure_cjk_font()` 后返回有效字体

### 7.2 i18n_set_lang 详解

```c
bool i18n_set_lang(lang_t lang)
{
    if (lang == g_current_lang) return true;  // 无变化

    /* 1. 写持久化文件 */
    int fd = open(LANG_CONFIG_FILE, O_WRONLY | O_CREAT | O_TRUNC, 0644);
    const char *data = (lang == LANG_EN) ? "en" : "zh";
    write(fd, data, 2);
    close(fd);

    /* 2. 更新内存状态 */
    g_current_lang = lang;

    /* 3. 字体处理 */
    if (lang == LANG_ZH_CN) {
        i18n_ensure_cjk_font();  // 切中文：确保CJK字体已加载
    }
    /* 切英文：不立即释放CJK字体！
     * 原因：lang_screen 上的 label 仍在使用该字体，删除会导致死机 */

    /* 4. 不立即广播！设置延迟标记 */
    s_lang_pending = true;

    return true;
}
```

### 7.3 lang_exit_to_settings 详解

这是整个切换流程中最关键的函数，负责在用户右滑返回时重建所有需要刷新的页面：

```c
static void lang_exit_to_settings(void)
{
    bool need_rebuild = s_language_changed;
    s_language_changed = false;

    if (need_rebuild)
    {
        /* 1. 重建设置页 */
        settings_page_deinit();
        settings_screen = lv_obj_create(NULL);
        create_settings_page(settings_screen);  // 文字会用新语言

        /* 2. 重建菜单页 */
        if (menu_screen) menu_page_force_delete();
        menu_screen = lv_obj_create(NULL);
        create_menu_page(menu_screen);

        /* 3. 销毁功能页屏幕（下次进入时重建） */
        ai_page_deinit();
        meeting_page_deinit();
        camera_page_deinit();
        camera_screen = NULL;  // camera_page_deinit 无法置空全局指针，需手动

        lv_scr_load_anim(settings_screen, LV_SCR_LOAD_ANIM_MOVE_RIGHT, 300, 0, false);

        /* 4. 延迟广播：通知主页刷新 */
        i18n_flush_lang_changed();
    }
    else
    {
        /* 未变更语言：直接返回设置页
         * Bug修复：settings_screen 可能已被卸载回调销毁，需重建 */
        if (settings_screen == NULL) {
            settings_screen = lv_obj_create(NULL);
            create_settings_page(settings_screen);
        }
        lv_scr_load_anim(settings_screen, LV_SCR_LOAD_ANIM_MOVE_RIGHT, 300, 0, false);
    }
}
```

## 8. 各页面的语言适配方式

### 8.1 页面分类

根据页面是否常驻，采用不同的语言刷新策略：

| 页面类型 | 页面 | 刷新策略 | 原因 |
|----------|------|----------|------|
| **常驻页** | main_screen（主页） | 回调原地刷新 | 避免重建闪烁，时钟不能中断 |
| **重建页** | menu_screen、settings_screen | 切换时立即重建 | 文字多，原地刷新复杂 |
| **按需重建页** | ai/meeting/camera/recorder/player | 销毁屏幕，下次进入重建 | 用户不一定使用，节省内存 |

### 8.2 主页（xiaoq_page.c）— 回调原地刷新

主页是常驻屏幕，注册了语言变更回调，切换语言时原地刷新字体和文字：

**注册回调**（[xiaoq_page.c:286](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/xiaoq_page.c#L286)）：
```c
i18n_register_lang_cb(homepage_lang_changed_cb);
```

**回调实现**：
```c
static void homepage_lang_changed_cb(lang_t lang)
{
    /* 1. 先把 label 字体设为安全值，避免悬空指针 */
    lv_obj_set_style_text_font(time_label, &lv_font_montserrat_24, 0);
    lv_obj_set_style_text_font(date_label, &lv_font_montserrat_24, 0);
    lv_obj_set_style_text_font(weekday_label, &lv_font_montserrat_24, 0);

    /* 2. 删除旧 FreeType 字体 */
    homepage_font_unload();

    /* 3. 按新语言加载新字体（中英文字号不同） */
    homepage_font_load(lang);

    /* 4. 应用新字体到 label */
    lv_obj_set_style_text_font(time_label, time_font, 0);
    lv_obj_set_style_text_font(date_label, date_font, 0);
    lv_obj_set_style_text_font(weekday_label, weekday_font, 0);

    /* 5. 刷新日期/星期文字（格式不同） */
    homepage_update_datetime();
}
```

**主页字体字号差异**：

| 元素 | 中文 | 英文 | 原因 |
|------|------|------|------|
| 时钟 | 120px | 100px | 英文数字较宽，缩小避免溢出 |
| 日期 | 39px | 48px | 英文"Jul 21"比"7月21日"短，字号调大更协调 |
| 星期 | 39px | 39px | 中英文都是短词，字号相同 |

### 8.3 菜单页（menu_page.c）— 重建刷新

菜单页没有注册语言回调，切换语言时通过 `menu_page_force_delete()` 删除后重建：

## 9. 页面重建机制详解

### 9.1 屏幕生命周期管理

LVGL 的屏幕（`lv_obj_t *screen`）是顶级对象，切换屏幕用 `lv_scr_load_anim()`。本项目的屏幕管理采用**静态全局指针 + 懒创建**模式：

```c
/* 各页面的全局屏幕指针（定义在各自 .c 文件或 lvgldemo.c 中） */
lv_obj_t *main_screen     = NULL;  // 主页（常驻，开机创建）
lv_obj_t *menu_screen     = NULL;  // 菜单页
lv_obj_t *settings_screen = NULL;  // 设置页
lv_obj_t *camera_screen   = NULL;  // 相机页
lv_obj_t *ai_screen       = NULL;  // AI页
lv_obj_t *meeting_screen  = NULL;  // 会议页
/* ... */
```

### 9.2 进入页面的统一模式

所有功能页进入时都遵循「空则创建，非空则复用」模式：

```c
static void menu_enter_xxx_page(void)
{
    if (xxx_screen == NULL) {           // 首次进入或切语言后销毁
        xxx_screen = lv_obj_create(NULL);
        create_xxx_page(xxx_screen);    // 创建UI（使用i18n_get获取当前语言文字）
    }
    lv_scr_load_anim(xxx_screen, ...);  // 切换到该屏幕
}
```

### 9.3 屏幕卸载回调（SCREEN_UNLOADED）

部分页面注册了 `LV_EVENT_SCREEN_UNLOADED` 回调，在屏幕被切走后异步销毁：

```c
/* settings_page.c */
lv_obj_add_event_cb(parent, settings_screen_unloaded_cb,
                    LV_EVENT_SCREEN_UNLOADED, NULL);

static void settings_screen_unloaded_cb(lv_event_t *e)
{
    lvgl_dispatch_async(settings_deinit_async_cb, NULL);
}
```

**与语言切换的交互**：这导致了 Bug1（右滑返回失败），详见第11节。

### 9.4 为什么不原地刷新所有页面？

| 方式 | 优点 | 缺点 |
|------|------|------|
| **原地刷新** | 无闪烁，省内存 | 需为每个 label 调用 `lv_label_set_text()`，页面多时代码冗长易漏 |
| **重建页面** | 代码简洁，自动刷新 | 有短暂闪烁，需正确销毁旧屏幕避免内存泄漏 |

本项目对功能页采用重建方式，因为：
1. 功能页文字较多（如相机页有标题、状态、按钮、提示等十余处）
2. 功能页用户不一定使用，重建开销可接受
3. 避免为每个页面维护繁琐的原地刷新逻辑

## 10. 延迟广播机制（关键设计）

### 10.1 问题背景

最初的设计是 `i18n_set_lang()` 中同步广播语言变更事件，但导致了严重崩溃：

```
i18n_set_lang(EN)
  └─ 同步广播 → homepage_lang_changed_cb(EN)
       └─ homepage_font_unload()  // 删除旧字体
       └─ homepage_font_load(EN)  // 加载新字体
            └─ FreeType 字体重建过程中...
                 └─ LVGL 异步渲染访问已删除字体
                      └─ Instruction access violation (PC=0x00000000) 死机
```

**根因**：`lang_screen` 仍是活动屏幕时，LVGL 的异步渲染线程可能正在绘制使用旧字体的 label。同步删除字体会导致渲染线程访问已释放内存。

### 10.2 解决方案：延迟广播

将广播拆分为两步：

**第一步：设置标记（在 `i18n_set_lang` 中）**
```c
bool i18n_set_lang(lang_t lang)
{
    /* ... 写文件、更新状态 ... */
    s_lang_pending = true;  // 只设标记，不广播
    return true;
}
```

**第二步：延迟广播（在退出语言页时）**
```c
void i18n_flush_lang_changed(void)
{
    if (!s_lang_pending) return;
    s_lang_pending = false;

    lang_t lang = g_current_lang;
    for (int i = 0; i < MAX_LANG_CBS; i++) {
        if (s_lang_cbs[i]) {
            s_lang_cbs[i](lang);  // 调用主页回调
        }
    }
}
```

**调用时机**：在 `lang_exit_to_settings()` 中，**所有页面重建完成后**才调用：

```c
static void lang_exit_to_settings(void)
{
    if (need_rebuild) {
        settings_page_deinit();         // 重建设置页
        ...
        menu_page_force_delete();       // 重建菜单页
        ...
        ai_page_deinit();               // 销毁功能页
        ...

        lv_scr_load_anim(settings_screen, ...);  // 切到设置页

        i18n_flush_lang_changed();      // ★ 最后才广播给主页
    }
}
```

### 10.3 为什么这样安全？

```
时间线：
  t1: i18n_set_lang()      → 设标记，不广播
  t2: 用户看到"切换成功"
  t3: 用户右滑返回
  t4: 重建 settings/menu   → 旧屏幕已删除
  t5: 销毁功能页屏幕       → 所有非 main 屏幕已清理
  t6: lv_scr_load_anim(settings_screen)
  t7: i18n_flush_lang_changed()
       └─ homepage_lang_changed_cb()
            └─ 此时活动屏幕是 settings_screen（非 lang_screen）
            └─ lang_screen 已被销毁，不存在悬空引用
            └─ 主页 label 字体可安全替换
```

## 11. 开发过程中的问题与解决方案

### 11.1 Bug1：语言页右滑返回失败（未切换语言时）

**现象**：进入语言页不切换语言，右滑无法返回设置页。

**根因**：进入语言页时，`lv_scr_load_anim(lang_screen, ...)` 会使旧的 `settings_screen` 触发 `SCREEN_UNLOADED` 事件，异步调用 `settings_page_deinit()` 销毁 `settings_screen` 并置空。右滑返回时 `settings_screen == NULL`，导致无屏幕可切。

**修复**：在 `lang_exit_to_settings()` 的 else 分支（未变更语言）中检查并重建：
```c
else {
    if (settings_screen == NULL) {  // 被卸载回调销毁了
        settings_screen = lv_obj_create(NULL);
        create_settings_page(settings_screen);
    }
    lv_scr_load_anim(settings_screen, ...);
}
```

### 11.2 Bug2：AI页状态文字未翻译

**现象**：切换到英文后，AI页的"正在监听..."、"AI回复中..."仍显示中文。

**根因**：[voice_assistant.c](file:///home/lzw/code/si8658ca/openvela_005_0701/openvela_si8658ca/rtos/apps/examples/lvgldemo/voice_assistant.c) 中使用了硬编码字符串而非 `i18n_get()`。

**修复**：替换为 i18n 调用：
```c
// 修复前
voice_assistant_update_status("正在监听...");
// 修复后
voice_assistant_update_status(i18n_get(STR_AI_LISTENING));
```

### 11.3 Bug3：切换语言后渲染崩溃（PC=0x00000000）

**现象**：切换语言时设备死机，串口日志显示 `Instruction access violation (PC=0x00000000)`。

**根因**：同步广播导致 `lang_screen` 上的 label 引用已删除的 FreeType 字体。

**修复**：实现延迟广播机制（见第10节）。

### 11.4 Bug4：英文模式下中文显示方框

**现象**：英文模式下语言页的"简体中文"选项显示为方框。

**根因**：`i18n_get_cjk_font()` 在英文模式下返回 NULL，label fallback 到 montserrat 字体（不含中文）。

**修复**：`i18n_get_cjk_font()` 始终调用 `i18n_ensure_cjk_font()` 确保字体已加载：
```c
lv_font_t *i18n_get_cjk_font(void)
{
    i18n_ensure_cjk_font();  // 总是确保加载
    return s_cjk_font;
}
```

### 11.5 Bug5：相机页标题未翻译

**现象**：切英文后相机页标题仍为"图文智录"，切中文后仍为"AI Camera"。

**根因**：`camera_page_deinit()` 删除了屏幕对象但无法置空全局 `camera_screen` 指针（定义在 lvgldemo.c）。下次进入时 `menu_enter_camera_page()` 检测到 `camera_screen != NULL`，复用旧屏幕，文字不刷新。

**修复**：在 `lang_exit_to_settings()` 中手动置空：
```c
camera_page_deinit();
camera_screen = NULL;  // 手动置空，强制下次重建
```

### 11.6 Bug6：异步重建导致崩溃

**现象**：尝试用 `lvgl_dispatch_async(lang_rebuild_async_cb, NULL)` 异步重建页面时崩溃。

**根因**：异步在 timer handler 中执行，此时 LVGL 状态可能不一致。

**修复**：改为同步重建（直接在 `lang_exit_to_settings()` 中执行）。

### 11.7 Bug7：英文模式时钟字号偏小

**现象**：英文模式下时钟和日期字体比中文模式小很多。

**根因**：最初英文模式回退到 `montserrat_24`（24px），而非加载 MiSans 字体。

**修复**：
1. `i18n_apply_font()` 中英文均使用 MiSans 28px
2. 主页时钟英文字号从 80px 调整为 100px，日期从 39px 调整为 48px

### 11.8 Bug8：WiFi 页面语言适配回退

**现象**：WiFi 页面切换语言后文字不刷新，且扫描按钮文字切换时按钮缩小。

**决策**：WiFi 页面不适配中英文，还原为固定英文显示。

**修复**：
1. 移除 wifi_page.c 中所有 `i18n_get()` 调用，改为硬编码英文字符串
2. 移除 `i18n_apply_font` 调用，改用 `lv_font_montserrat_24`
3. 扫描按钮宽度从 `LV_SIZE_CONTENT` 改为固定 240px
4. 清理 i18n.h/i18n.c 中的 `STR_WIFI_*` 枚举和字符串表
